# Admin V2 retired route

The non-Figma Admin V2 interface has been removed from the production entry points. `/admin-v2/`, `/admin-v2/workbench/`, and `/admin-v2/legacy.html` now redirect to the existing `/admin/` admin.

The Figma-inspired `terra` design remains a separate local preview and has not been published. Tajweed editor and Arabic keyboard assets remain available for that prototype while the replacement interface is prepared.
