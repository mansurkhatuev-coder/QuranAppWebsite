# Админка V2 — отдельный предпросмотр

Эта папка содержит тестовую оболочку новой админки. Прежние экраны доступны по кнопке «Старый вариант» внутри оболочки и используют ту же блокировку записей. Код production-админки в этой работе не заменён.

## Запуск локального предпросмотра

Из корня рабочей копии запустите локальный HTTP-сервер:

```powershell
py -m http.server 8783 --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:8783/admin-v2/`. Для корректной работы iframe и JSON-снимков не открывайте `index.html` напрямую как файл.

## Что можно посмотреть и редактировать

| Раздел | Источник и режим | Ограничения |
| --- | --- | --- |
| Обзор | Локальные снимки для счётчиков и локальная история черновиков | Счётчик азкаров — по включённому тестовому снимку; это не полный каталог приложения |
| Единый редактор | Локальные JSON-снимки дуа, азкаров и таджвид-документов; единый поиск и карточка материала | Идентификаторы и связи не переписываются; правки и новые записи остаются в localStorage этого браузера |
| Таджвид | Копия специализированного редактора с его разметкой, нормализацией, шрифтами и арабской клавиатурой | Чтение опубликованного пакета разрешено; черновики только локальные; загрузка из production и публикация не выполняются |
| Старые разделы админки | Подключены исходные экраны аналитики, главной, отзывов, обновлений, розыгрыша и состояния сайта | Запросы чтения разрешены; все изменения в backend заблокированы до появления staging-среды |
| Переводы интерфейса | Копия CE-редактора | Изменения остаются локальным черновиком |
| Старые редакторы | Кнопка в верхней панели | Сохраняет локальный черновик перед переходом, если редактор подтверждает сохранение |

Арабская клавиатура сохраняет группы, знаки, выбор шрифта и его настройки; она доступна в редакторе материала и в таджвид-редакторе. На телефоне поле остаётся над полноэкранной клавиатурой. В таджвид-редакторе полная палитра правил и остальные команды сохранены, а вспомогательные панели можно раскрыть при необходимости.

Кнопка «Старый вариант» всегда находится в верхней панели. При несохранённых правках она предлагает сохранить локальный черновик, остаться в редакторе или перейти без изменений.


## Аналитика

На обзоре график можно выбирать мышью и клавиатурой: выбранная дата показывает значения обеих серий. Если авторизация для старого модуля аналитики ещё не выполнена, график показывает только явно помеченную демонстрационную выборку с бейджем «ДЕМО». После входа он переключается на доступные реальные ряды из read-only источника; значения отсутствующих дат остаются пропусками. Демо-значения не подмешиваются в реальные данные.

При открытии выбирается период «за всё время». Тестовая оболочка не вызывает `analytics_dashboard`: текущая SQL-функция обновляет таблицу `analytics_daily` при чтении. Вместо этого предпросмотр читает таблицу напрямую и показывает фактический диапазон доступных дневных точек. Это покрытие таблицы, а не подтверждение полной истории; графики и карточки не называют его полной историей. Счётчик установок запрашивается отдельно через read-only RPC/агрегат.

SQL-миграции в составе этого предпросмотра нет. V2 читает таблицу дневной аналитики напрямую, не вызывая RPC, которое может обновлять агрегаты при чтении. Таблица покрывает только доступные даты; интерфейс не выдаёт это за полную историю без подтверждающих метаданных.

Импортированные отчёты магазинов показываются отдельно от установок приложения, а пропущенные дни не подменяются нулями. В тестовом предпросмотре RuStore и Google Play CSV можно загрузить вручную: файл разбирается в браузере, объединяется по датам и сохраняется в отдельном ключе `localStorage` этой версии. Загрузка в backend и автоматическое обновление App Store/Google Play отключены. При наличии доступной истории из базы график показывает её вместе с локально импортированными датами и явно отмечает локальный CSV.

## Граница безопасности

- В тестовой оболочке нет действий публикации контента в приложение.
- В таджвид-копии флаг test-only включён постоянно, а Supabase-клиент для записи не подключён.
- Запросы изменения из старых модулей перехватываются до отправки; вход и разрешённые операции чтения отделены от записи.
- Локальные черновики хранятся в `localStorage` этого браузера. Очистка данных браузера удалит их.
- Старые модули пока не имеют полноценного локального симулятора сохранения. Для проверки их редактирования, публикации баннеров, обновлений, отзывов и других серверных действий сначала нужна staging-база и безопасные тестовые учётные данные.
- На production новый путь доступен как отдельный предпросмотр после публикации этой версии; старая `/admin/` остаётся рабочей. Изменения контента и публикация из V2 остаются отключены до отдельной проверки реального API и схемы.
