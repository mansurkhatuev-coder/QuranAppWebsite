# Рекламное демо-древо

Страница: https://waydean.ru/drewo-reklama/

## Вход

На экране уже выбраны **Ислам** и пароль **`демо`** — достаточно нажать **Войти в демо**.  
Можно выбрать любое другое имя из списка; пароль тот же (`демо`).

## Это витрина, не ваше древо

- Имена **вымышленные**
- **Фото отключены**
- Не больше **90** человек (чтобы не раздували демо под свой род)
- **Пароль семьи сменить нельзя**
- Плашка «Демо, не ваше древо» всегда на экране

Своё древо создаётся отдельно (заказ / кабинет Trees), не через эту страницу.

## Правки в демо

Можно посмотреть карту и слегка попробовать связи в пределах лимита.  
Суперпароль `DREWO_REKLAMA_SUPER_PASSWORD`: бэкапы и служебные действия для вас.
