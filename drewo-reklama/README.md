# Некъ — демо-древо для рекламы

Страница: https://waydean.ru/drewo-reklama/

Отдельное вымышленное древо, чтобы **не светить** личные `/drewo/` и `/drewo-dada-yurt/` в роликах и скриншотах.

## Вход

На экране уже выбраны **Ислам** и пароль **`демо`** — достаточно нажать **Войти в демо**.
Можно выбрать любое другое имя из списка; пароль тот же (`демо`, либо сменённый в «Управление»).

## Правки

- Обычный пароль: связи, сохранение, фото.
- Суперпароль `DREWO_REKLAMA_SUPER_PASSWORD`: бэкапы, блок правок, смена пароля.
- «Сохранить» через `publish-drewo` с `treeDir: "drewo-reklama"`.
- Вид по умолчанию: все линии; «Линия Берса» — фильтр.

## Данные

Все имена и годы — **вымысел** для демонстрации продукта.
