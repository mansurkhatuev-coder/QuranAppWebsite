# Waydean Family Story — локальное Remotion preview

Изолированная студия первого видео-шаблона «История рода». По умолчанию она читает локальный снимок `drewo/family-tree.json`: 157 записей, 14 поколений и 156 связей. В модель не попадают внешние сервисы; страница не меняет приложение или production.

## Запуск

Из этой папки:

```powershell
npm run export-studio
```

Открой `http://127.0.0.1:8781/` (или порт, указанный в `WAYDEAN_EXPORT_STUDIO_PORT`). Настройки позволяют менять заголовок, область (`all`, `path`, `branch`), центрального человека и показ дат. Выбор и заголовок сохраняются только в localStorage этого браузера.

## Данные и сцены

- При сборке сохраняются ID, имя, доступные даты и исходная связь родитель–ребёнок. Данные только читаются.
- В исходном JSON нет пригодных для локального отображения адресов портретов; карточки показывают нейтральный силуэт. Отсутствующие даты остаются неизвестными.
- Все 156 связей рисуются постоянно приглушёнными линиями. Золотой свет последовательно проходит по пути выбранного человека, а на сценах ветвления выделяет настоящие связи.
- Компоновка автоматически увеличивает рабочую ширину и высоту для 40 человек в одном поколении и 14 строк, сохраняя зазор между карточками.
- Переключение сцен рисуется одним непрерывным деревом. Камера не дублирует и не замораживает предыдущий кадр; выделение людей и ветвей плавно передаётся за 36 кадров (1,2 секунды).
- Группы поколения разбиваются на сцены максимум по три человека. Камера мягко доезжает до центра сцены за 36 кадров, удерживает композицию до следующего движения, а щелчок по сцене сразу показывает уже собранный кадр.
- На общем плане все 157 записей остаются отдельными узлами, а 156 линий соответствуют сохранённым связям родитель–ребёнок. Читаемые имена появляются на близких планах поколений; общий план служит картой структуры.
- В ленте раскадровки каждая сцена получает мини-схему своего фрагмента дерева с фактическими родственными связями и участниками кадра. Выбранная сцена подсвечивается, а при воспроизведении лента плавно держит текущую главу в поле зрения.
- При охвате «Всё дерево» локальная раскадровка содержит 112 сцен. Мини-схемы используют ту же геометрию дерева; это компактный обзор сцены, не отдельный кадр и не готовая заставка.

Живой Player работает при 30 FPS и позволяет проверять утверждённое направление трёх форматов: 16:9 — 1920 × 1080, 9:16 — 1080 × 1920 и 1:1 — 1080 × 1080. Камера подгоняется к участникам сцены, а затемнённая safe area оставляет место для титров. Полные локальные 1080p MP4 revision 2 уже собраны; их окончательная визуальная приёмка остаётся отдельным шагом.

Кнопка добавляет тестовый MP4 в локальную FIFO-очередь Remotion. Выполняется один рендер за раз, ещё до трёх заданий могут ожидать; файлы формируются в двух третях выбранного размера: 1280 × 720, 720 × 1280 или 720 × 720. Это быстрый тестовый рендер, не мастер-разрешение. Утверждённое направление локального кандидата — 16:9 1920 × 1080, 9:16 1080 × 1920 и 1:1 1080 × 1080; полные файлы-кандидаты рендерятся напрямую из композиции отдельной командой Remotion CLI. Состояние заданий очереди атомарно сохраняется в `waydean-local-render-jobs` внутри настроенной временной папки, а готовые тестовые файлы остаются в `waydean-local-renders` и доступны по локальной ссылке скачивания. Здесь нет production worker, облачного хранилища или публичной публикации.

Чтобы складывать bundle, профиль Chromium и готовые файлы на диск с местом, задай пользовательскую временную папку перед запуском. Пример для PowerShell:

```powershell
$env:WAYDEAN_EXPORT_TEMP_DIR = "H:\CodexBuildTemp\WaydeanRemotion"
$env:WAYDEAN_RENDER_CONCURRENCY = "1" # optional: reduce RAM use for local review
npm run export-studio
```

Local Remotion rendering defaults to 25% of the logical CPU count. On this 12-core machine that opens three frame-rendering workers; use WAYDEAN_RENDER_CONCURRENCY=1 on a memory-limited workstation. The setting accepts a positive worker count or a percentage from 1% to 100%. This local tuning does not configure or deploy the future server-side worker.

Если переменная не задана, используется системная временная папка. Chrome или Edge должны быть уже установлены; для нестандартного пути к браузеру можно задать `WAYDEAN_REMOTION_BROWSER`.

Локальный сервер один раз собирает Remotion bundle и кэширует его до завершения процесса. После изменений в `src/` останови и запусти export studio заново перед новым рендером; иначе MP4 может содержать предыдущую версию кода.

## Локальная очередь заданий

- Сервер обслуживает один Remotion render одновременно. `POST /api/render` добавляет задание в FIFO-очередь; допускается до трёх ожидающих заданий. Переполненная очередь отвечает `429` с локальным сообщением.
- Манифесты хранятся атомарно в `waydean-local-render-jobs` внутри `WAYDEAN_EXPORT_TEMP_DIR` или системной временной папки. В них находятся только UUID, состояние, процент, безопасная стадия, настройки рендера и безопасная ошибка. Пути к файлам не загружаются из манифеста: путь готового MP4 выводится из проверенного UUID.
- При перезапуске очередные задания восстанавливаются. Задания, прерванные во время подготовки/рендера, становятся неудачными и их можно повторить: частичный рендер Remotion не продолжается.
- Отмена ожидающего задания действует сразу. Для активного задания сервер передаёт `makeCancelSignal()` в `renderMedia`; отмена подготовки композиции применяется перед началом рендера. Удаляется только частичный MP4 отменённого задания. Завершённые файлы автоматически не удаляются.
- Повтор одного задания создаёт связанное задание только один раз; повторный запрос после потери ответа или перезапуска возвращает уже созданное задание. Ошибка чтения готового MP4 переводит задание в повторяемую ошибку.
- Студия загружает историю заданий при открытии, обновляет её при активной очереди, показывает позицию и прогресс, а также предлагает отмену, повтор и скачивание.
- API привязано к loopback и служит только локальным прототипом. Здесь нет пользовательской авторизации, общего снимка дерева/фото, отдельного production worker, облачного хранилища, срока хранения или интеграции с рабочим приложением. `/api/render/:id/download` — локальная выдача, не защищённая пользовательской сессией.
