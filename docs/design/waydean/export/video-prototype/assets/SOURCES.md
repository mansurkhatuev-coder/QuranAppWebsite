# Video export assets

- The cinematic whoosh is synthesized in the browser from generated noise and a low frequency sweep. Mixkit's current transition sound collection was researched as a style reference, but no third-party sound file is distributed with the editor.
- `tus.min.js` — `tus-js-client` 4.3.1, included locally so resumable uploads do not depend on a runtime CDN request. MIT license: see `TUS-LICENSE.txt`.
