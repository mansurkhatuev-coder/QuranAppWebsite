# Waydean «Древо» — локальный mobile prototype

**Статус:** статический визуальный prototype для review; не production-интерфейс  
**Размер review-кадра:** 390 × 844 CSS px  
**Данные:** 12 вымышленных людей, без фотографий и серверного подключения

## Открыть

Открой `index.html` в Edge или Chrome. Если браузер блокирует локальные ресурсы, запусти любой локальный static file server из корня репозитория и открой выданный адрес. Prototype не подключается к Supabase, API или реальным данным.

Состояние можно открыть напрямую, добавив параметр `?state=` к `index.html`:

| Кадр | Параметр |
| --- | --- |
| Древо | `tree` |
| Профиль | `profile` |
| Поиск с результатами | `search` |
| Поиск без совпадений | `searchEmpty` |
| Меню «Ещё» | `menu` |
| Переключение режима | `modes` |
| Фильтры | `filters` |
| Пустой результат фильтра | `filtersEmpty` |
| Статистика | `stats` |
| Список людей | `people` |
| «Мой путь» | `path` |
| «Моя ветвь» | `branch` |
| Длинное имя и неизвестная дата смерти | `longName` |

## Демо-взаимодействия и ограничения

- Нажатие карточки синхронизирует выбранного человека с нижней карточкой и профилем.
- Поиск находит людей по имени, годам и ветви; одинаковые имена различаются поколением и датами.
- Меню открывает режимы, фильтры и статистику. Поделиться, Печать и Создать видео явно обозначены как недоступные в этом макете.
- Фильтры применяются к демо-данным; пустой результат объясняется, а сброс возвращает людей.
- Мини-карта и масштабирование здесь визуальные элементы и не управляют геометрией древа.
- В тестовом наборе все записи без фотографии. Каждый аватар использует один и тот же нейтральный силуэт головы и плеч без лица, глаз, носа и рта.
- Силуэт построен на Font Awesome Free `user` path; источник — Font Awesome Free, лицензия CC BY 4.0.
- Прототип показывает 7 узлов на видимой композиции, а 12 записей используются для поиска, списка и статистики. Это помогает проверить состояния на большем наборе без уплотнения единственного мобильного кадра.
- В статических review-состояниях нет реального сохранения, авторизации, печати, видео, motion, адаптивного LOD или performance-оптимизаций.

## Motion preview v0.5

Для отдельного review-сценария добавь `&motion=1` к URL состояния, например `index.html?state=path&motion=1`. Затем выбери «Мой путь» в меню, чтобы запустить последовательность повторно.

- Используется тот же набор из 12 фиктивных записей и тот же утверждённый мобильный кадр.
- Связи строятся по фактическим границам карточек и соединяются единым набором аккуратных поворотов; подтверждённый путь проявляется по порядку.
- Камера одновременно набирает масштаб и проходит от предка к потомку через карточки и по геометрии SVG-связей как один непрерывный пролёт без остановок и разворотов на границах сегментов.
- Зум нарастает от общего плана 1× до 1,46× за тот же непрерывный ход. Выбранная карточка плавно приходит в центр полотна и остаётся там после остановки.
- В полёте карточки и связь маршрута сменяют друг друга в акценте; в финале яркой остаётся выбранная карточка, линия к предку видна приглушённо, а остальные карточки, включая детей выбранного человека, остаются на месте без конкурирующей золотой подсветки.
- Связи прорисовываются синхронно с точкой движения камеры, мини-карта перемещается по пути.
- Название режима размещено в стороне от карточек, чтобы не перекрывать имена и даты.
- Новый выбор, открытие панели или системное уменьшение движения прерывают/упрощают эффект; без JavaScript-эффекта остаётся статический путь.
- Motion включается только параметром `motion=1`; обычные состояния и сохранённые скриншоты остаются статичными.
- Это ранний локальный арт-прототип: здесь нет реального дерева 157 человек, LOD, адаптации High/Medium/Low и замеров на телефоне.

## Что проверено локально

- Открытие всех описанных состояний без ошибок JavaScript.
- Выбор узла, открытие соответствующего профиля, поиск и выбор длинного имени.
- Переключение в «Мой путь».
- Пустое состояние фильтра и возврат после сброса.
- Скриншоты созданы для review-кадров; дальнейший визуальный блок начинается только после утверждения мобильного прохода.
