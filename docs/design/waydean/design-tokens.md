# Waydean «Древо» — Design Tokens

**Версия:** 0.2  
**Статус:** стартовый набор значений для согласования и проверки на Master-кадрах  
**Дата:** 2026-09-28  
**Связанные документы:** [общая спецификация](product-design-spec.md), [Design Bible v1](design-bible-v1.md)

> Таблица разделяет значения уже существующей Premium-темы и проектные предложения. Значения из кода служат базой Waydean; предложения для типографики и ритма — исходной сеткой для Desktop/Mobile Master. Это ещё не финальные токены интерфейса.

## 1. Источник базовой палитры

Проверенная локальная копия [`drewo/index.html`](https://github.com/mansurkhatuev-coder/QuranAppWebsite/blob/main/drewo/index.html#L20-L46) содержит Premium-тему с тёмной сине-зелёной палитрой, тёплым золотом и светлым текстом. Локальная копия репозитория отстаёт от `main`; перед переносом токенов в код значения нужно повторно сверить с актуальной веткой. Это существующая база, а не автоматически утверждённый новый UI.

### 1.1 Существующие значения Premium

| `color.bg.forest` | `#173028` | Второй уровень фона | Есть в Premium-теме |
| `color.bg.depth` | `#2C4638` | Акцент глубины/фоновых слоёв | Есть в Premium-теме |
| `color.gold.primary` | `#E2C48A` | Основной тёплый золотой акцент | Есть в Premium-теме |
| `color.gold.muted` | `#B89555` | Приглушённое золото | Есть в Premium-теме |
| `color.text.primary` | `#F7F1E6` | Основной светлый текст | Есть в Premium-теме |
| `color.text.secondary` | `color-mix(in srgb, var(--text) 62%, transparent)` | Вторичный текст | Есть в Premium-теме; контраст проверить на финальных поверхностях |
| `color.surface.panel` | `color-mix(in srgb, #0A141A 80%, black)` | Основные панели Premium | Есть в Premium-теме |

Выражения с `var(--text)` и `var(--sand)` ссылаются на переменные действующего CSS. При реализации именованных токенов их нужно заменить на ссылки внутри новой системы. Цвет `#030910` есть в градиенте ночного фона, но не задан как переменная Premium-темы. Нейтральная тема из тех же CSS (`#12262F`, `#1E3D36`, `#2A5246`, `#D4B483`, `#A8895A`, `#F3EBE0`) не переносится автоматически в новый премиальный вариант.

Для `color.bg.canvas` нужен отдельный фон под древом, а для `color.selected.glow` — цвет локального свечения. Их значения пока открыты: фон и свечение зависят от Desktop Master и проверки читаемости карточек поверх изображения.

## 2. Начальная типографика

Текущий код подключает `Cormorant Garamond` и `Source Sans 3` из Google Fonts. Это кандидаты для нового дизайна, потому что они поддерживают нужное разделение выразительных заголовков и читаемого UI. До фиксации проверить русские и реальные длинные имена в проекте; если нужные письменности не покрываются, подобрать замену.

| Токен | Стартовое значение | Применение | Статус |
| --- | --- | --- | --- |
| `font.display` | `Cormorant Garamond`, fallback `Georgia`, serif | Бренд и крупные эмоциональные заголовки | Кандидат из текущего сайта |
| `font.ui` | `Source Sans 3`, fallback `Segoe UI`, `Noto Sans`, sans-serif | Интерфейс, имена, даты, фильтры, статистика | Кандидат из текущего сайта |
| `font.weight.regular` | `400` | Основной UI | Есть в загрузке текущего сайта |
| `font.weight.semibold` | `600` | Навигация, имена, кнопки | Есть в загрузке текущего сайта |
| `font.weight.display` | `600` | Крупные заголовки/бренд | Есть в загрузке текущего сайта |
| `font.weight.display.strong` | `700` | Более сильный брендовый акцент | Есть в загрузке текущего сайта |

Это начальные размеры для сборки Master; на них проверяются длинные имена, даты и плотность дерева. Значения фиксируются после просмотра desktop и mobile.

| Токен | Стартовый размер | Межстрочный интервал | Применение |
| --- | ---: | ---: | --- |
| `text.caption` | `12px` | `16px` | Подписи и вторичные метки |
| `text.body.small` | `13px` | `18px` | Вспомогательная информация |
| `text.body` | `15px` | `20px` | Основной интерфейс |
| `text.person.name` | `17px` | `21px` | Имя в карточке человека |
| `text.section.title` | `20px` | `25px` | Заголовок панели/раздела |

Все размеры указаны в CSS px. На телефоне допускается своя ступень для display и person card, когда это подтверждено Mobile Master; мелкий служебный текст не уменьшается ради умещения.

## 3. Пространство и геометрия

Текущий код содержит значения в rem и пикселях, но не единый шаг отступов. Для новых компонентов предлагается компактная шкала с шагом 4px; она должна пройти проверку на обеих Master-композициях.

| Токен | Стартовое значение | Типичное применение |
| --- | ---: | --- |
| `space.1` | `4px` | Микрорасстояние, иконка-текст |
| `space.2` | `8px` | Плотные внутренние интервалы |
| `space.3` | `12px` | Строки/контролы |
| `space.4` | `16px` | Стандартный внутренний отступ |
| `space.6` | `24px` | Разделение секций |
| `space.8` | `32px` | Крупный интервал |

| Токен | Стартовое значение | Роль |
| --- | ---: | --- |
| `radius.control` | `8px` | Поля и компактные элементы |
| `radius.card` | `12px` | Карточки и стандартные панели |
| `radius.panel.large` | `16px` | Крупная выдвижная панель/меню |
| `radius.pill` | `999px` | Круглые маркеры/пилюли, только где это уместно |
| `border.default` | `1px` | Спокойная граница |
| `border.selected` | `1.5px` | Выбранная карточка/активная рамка |

Точный размер карточек человека, верхней полосы, меню, правой панели, мини-карты, нижней навигации и мобильного sheet задаётся отдельными Desktop/Mobile Master. Эти значения нельзя вывести из коллажа с несколькими экранами.

## 4. Границы, тени и выделение

| Токен | Стартовое правило |
| --- | --- |
| `border.panel` | Значение пока открыто; ориентир из текущего CSS — смесь `var(--sand)` и прозрачного цвета в диапазоне `20–35%` |
| `shadow.panel` | Значение пока открыто; ориентир из существующей панели — `0 18px 42px` с чёрным цветом при `46%` непрозрачности |
| `glow.selected` | Локально вокруг выбранного человека/маршрута; точные blur и opacity выставить по Desktop Master, не применять ко всем карточкам |
| `overlay.scrim` | Тёмное затемнение фона при открытом меню/профиле; значение выбрать по контрасту и состоянию экрана |

Эти эффекты описывают стартовую систему, не прямое требование повторить каждое старое CSS-правило. Сдержанное свечение и читаемость важнее декоративной силы.

## 5. Семантические правила

- Основной текст всегда проходит проверку контраста на реальной панели и фоне; `color.text.secondary` из текущего CSS не считать автоматически подходящим для мелких подписей.
- Золото выделяет выбранное/активное и важные связи. Не использовать его для всего текста и всех рамок сразу.
- Выбранное состояние обозначается не только цветом: добавить форму рамки, маркер или иной видимый признак.
- Линия пути может быть ярче обычных родственных связей; сами обычные связи остаются различимыми.
- Для пустого фото используется токен поверхности/рамки и силуэт без черт лица; не добавлять генерируемые портреты.
- Публичные токены не содержат данных конкретных людей, имён, дат или фотографий.

## 6. Порядок утверждения

1. Согласовать стартовые значения и роли tokens по этой таблице.
2. Собрать Desktop Master с фиксированным окном и проверить цвет, типографику, плотность, карточки, отступы и контраст.
3. Уточнить общие значения и зафиксировать отдельные адаптивные tokens для mobile, если это нужно.
4. Собрать Mobile Master и проверить меню, нижнюю навигацию, поиск, мини-карту и раскрывающуюся карточку.
5. После принятия обоих Masters отметить финальные значения как утверждённые и только затем переносить их в код.

Механические значения motion (длительности, easing, LOD и уровни High/Medium/Low) сюда не включены: они фиксируются отдельно в Motion Bible. Печатные и видео токены появятся в своих системах.
