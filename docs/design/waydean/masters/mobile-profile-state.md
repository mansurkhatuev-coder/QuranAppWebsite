# Mobile Master — подробный профиль человека

Предложение отдельного экрана профиля для проверки следующего состояния. На него можно перейти из компактной строки выбранного человека; возврат ведёт обратно к тому же месту в дереве.

![Черновое состояние подробного профиля](mobile-profile-state.svg)

В кадре показан человек без загруженного фото, поэтому вместо портрета используется нейтральный силуэт головы и плеч без черт лица. Проверить нужно читаемость имени и фактов, ясность возврата к дереву, вкладки и заметность действия «Показать ветвь». Это черновой экран для обсуждения, не утверждённая спецификация.
