# Waydean «Древо» — Component Bible

**Версия:** 0.1  
**Статус:** рабочая спецификация для подготовки состояний и prototype  
**Базовые кадры:** Desktop 1440 × 900; Mobile 390 × 844 CSS px  
**Связанные документы:** [общая спецификация](../product-design-spec.md), [Design Bible v1](../design-bible-v1.md), [Design Tokens](../design-tokens.md), [Desktop Master](../masters/desktop-master.md), [Mobile Master](../masters/mobile-master.md)

> Этот документ описывает состав и состояния компонентов. Он не объявляет их реализованными и не заменяет Master-кадры. Точные размеры, цвета, интервалы, радиусы и тени берутся из согласованных tokens и Masters, а не выбираются при реализации на глаз.

## 1. Общие правила состояний

1. Один и тот же объект сохраняет выбранного человека и положение дерева при открытии профиля, меню, поиска, фильтров и статистики.
2. Состояния различаются не только цветом: использовать рамку, заливку, текстовую подпись, значок или изменение расположения.
3. Наведение существует только для устройств с указателем. Для телефона обязательны видимые состояния касания, выбора и возврата.
4. Фокус клавиатуры должен быть заметен и не сливаться с золотой рамкой выбранной карточки.
5. Загрузка, пустое состояние, ошибка и недоступное действие имеют понятный текст и способ продолжить работу, если он есть.
6. Недоступный экспорт нельзя показывать как готовую функцию. «Печать» и «Создать видео» получают доступное состояние только после реализации соответствующих потоков.
7. Motion описывается отдельно в [Motion Bible](../motion/motion-bible.md). Здесь зафиксированы конечные состояния и смысл переходов.

## 2. Карточка человека в дереве

**Назначение:** показать человека как узел родословной и дать безопасный способ выбрать его или раскрыть потомков.

**Состав:** фото или силуэт; имя; годы жизни, если известны; маркер раскрытия, только когда у человека есть скрытые потомки.

| Состояние | Вид и поведение |
| --- | --- |
| Обычное | Спокойная карточка; фото/силуэт, имя и даты читаются на фоне. |
| Наведение (desktop) | Тонкое усиление границы или поверхности; не конкурирует с выбранным человеком. |
| Фокус клавиатуры | Отдельный видимый контур; не меняет выбранного человека сам по себе. |
| Выбрано | Золотая рамка и локальное свечение вместе с дополнительным маркером или изменением контраста. Панель/строка выбранного человека показывает того же человека. |
| Раскрываемая ветвь | Отдельный маркер сообщает, что у человека есть скрытые потомки; он не выглядит как обычная стрелка перехода на профиль. |
| Ветвь раскрыта | Маркер и дочерние узлы отражают открытое состояние; повторное действие закрывает только эту ветвь. |
| Нет фотографии | Готовый нейтральный силуэт головы и плеч без лица; исходник и атрибуция лежат в SVG-эскизах. |
| Неполные данные | Неизвестные даты не заменяются выдуманными. Показывать только достоверные части диапазона или нейтральную подпись «даты неизвестны» в профиле. |
| Длинное имя | Имя переносится или сокращается по правилам Master; оно не закрывает маркер раскрытия и годы. Полное имя остаётся доступно в профиле. |
| Недоступен | Использовать только для действительно недоступного действия/узла; если человека можно открыть, карточка не должна выглядеть выключенной. |

Начальные габариты из макетов служат ориентирами: desktop около 104 × 136 px, mobile в эскизе 72 × 93 px. Перед фиксацией проверить длинные имена, малый масштаб, плотное поколение и реальные фото. Это не значения design tokens.

## 3. Выбранный человек и краткая строка Mobile

**Назначение:** сохранять видимую связь между выбранной карточкой дерева и открытием подробностей, не закрывая само древо.

**Состав:** миниатюра/силуэт, имя, годы жизни при наличии, короткий контекст (например, поколение), явный affordance открытия.

- Появляется после выбора узла; имя и данные совпадают с ним и с полным профилем.
- Нажатие по строке или стрелке открывает профиль того же человека.
- Закрытие профиля возвращает к прежнему масштабу и положению дерева.
- При отсутствии фото применяется тот же силуэт, что в карточке и профиле.
- Длинное имя не вытесняет стрелку; годовой диапазон может скрываться раньше имени.
- При смене выбранного человека строка обновляется без потери выбранного состояния дерева.

Эта мобильная строка не используется как постоянная боковая панель desktop.

## 4. Профиль человека

**Desktop:** правая панель рядом с деревом.  
**Mobile:** отдельный экран/развёрнутая панель с ясным возвратом к дереву; композиция [отдельного mobile-состояния](../masters/mobile-profile-state.md) пока является Master-кандидатом.

**Состав:** фото или силуэт, имя, годы при наличии, вкладки «Информация», «Родственники», «Медиа», структурированные факты и основное действие «Показать ветвь».

| Состояние | Требование |
| --- | --- |
| Информация | Значения выровнены, подписи вторичны, неизвестные факты не выдумываются. |
| Родственники | Счётчик отражает фактический состав; пустой список объясняет отсутствие данных. |
| Медиа | Миниатюры открывают медиа; пустое состояние не притворяется загруженным контентом. |
| Нет фото | Тот же нейтральный силуэт; без глаз, носа, рта, причёски или сгенерированного лица. |
| Длинное имя/нет дат | Имя сохраняет приоритет; даты скрываются, если неизвестны. |
| Возврат | Возвращает в прежнюю позицию дерева и сохраняет его состояние. |

## 5. Поиск человека

**Входы:** поле поиска в основном экране и отдельный экран/панель поиска на mobile.

| Состояние | Требование |
| --- | --- |
| Пустое | Короткая подсказка без фиктивных результатов. |
| Ввод | Текст не перекрывает очистку/закрытие; ввод не сбрасывается при временном переключении результата. |
| Загрузка | Спокойный индикатор; нельзя показывать устаревший набор как актуальный. |
| Результаты | Имя, годы если доступны, краткая родственная подпись и силуэт при отсутствии фото. Совпавший запрос выделяется деликатно. |
| Нет результатов | Ясно сообщить, что совпадений нет; дать очистить запрос или изменить его. |
| Ошибка | Объяснить, что поиск сейчас не выполнился; не подменять ошибку пустым результатом. |
| Выбран результат | Дерево плавно приходит к человеку; выбранная карточка и профиль относятся к одной записи. |

Фильтры поиска не должны молча скрывать результаты; активные фильтры видны и сбрасываются отдельно.

## 6. Навигация и меню «Ещё»

### Навигация Mobile

Пять подписанных пунктов: «Древо», «Люди», «Ветви», «Статистика», «Ещё». Каждый пункт имеет обычное, выбранное и фокусное состояния. Иконка не заменяет текст. Текущий пункт обозначается одновременно цветом и формой/маркером.

### Команды меню

- «Мой путь» — прямая линия от старшего известного предка до выбранного человека.
- «Моя ветвь» — фокус на ветви выбранного человека; если он не выбран, предлагается сначала выбрать его.
- «Все поколения» — полный набор ветвей без активного фильтра пути.
- «Фильтры» — открывает панель текущих ограничений и кнопку применения.
- «Статистика древа» — открывает сводку и распределение поколений.
- «Поделиться», «Печать», «Создать видео» — отдельные действия; доступность должна соответствовать реальной готовности функции.

Открытое меню имеет чёткую кнопку закрытия и не скрывает контекст текущего экрана. На mobile действия экспорта не должны путаться с нижней навигацией.

## 7. Полотно, связи и управление камерой

### Узлы и связи

- Линии соединяют только подтверждённые родственные связи и присоединяются к карточкам одинаковым способом.
- Обычная линия, выбранная линия и линия «Моего пути» различаются не только яркостью.
- При фильтрации нельзя показывать связь, если её родитель или потомок скрыт без объяснимого обозначения.
- На малом масштабе детали карточек упрощаются согласно будущим правилам LOD; структура и выбранный маршрут остаются различимы.

### Управление

- Увеличить / уменьшить — понятные отдельные кнопки с зонами касания по tokens.
- «Вписать дерево» — возвращает камеру к полному доступному древу.
- «Кто я?» — перемещает к человеку, назначенному текущим пользователем; если он не связан, показывает объяснимое пустое состояние и действие настройки.
- Мини-карта — показывает область текущего viewport и перемещает камеру по нажатию/перетаскиванию. На малом экране не закрывает строку выбранного человека и нижнюю навигацию.
- На desktop рамка мини-карты следует за камерой; стрелки клавиатуры пошагово перемещают вид. Полноэкранная кнопка раскрывает полотно дерева; та же кнопка и Escape возвращают к исходной компоновке, не меняя выбранного человека.
- При открытом профиле компактная камера поиска и пути центрируется в свободной области дерева, а не под панелью.
- Перетаскивание полотна не должно активировать карточку случайно; карточка активируется отдельным нажатием.

## 8. Режимы дерева и фильтры

### Режимы

- **Мой путь:** акцентирует подтверждённую прямую линию; остальные люди остаются видимыми приглушённо либо скрываются только согласно явно выбранной настройке.
- **Моя ветвь:** оставляет в фокусе потомков/предков выбранного человека согласно принятому определению ветви.
- **Все поколения:** снимает фильтр маршрута и показывает доступное древо целиком.

У режима есть заметное активное состояние и простой способ вернуться к «Все поколения». Переключение режима не меняет данные и не стирает фильтры без уведомления.

### Фильтры

Поддерживаемые критерии из текущего плана: поколения/диапазон поколений, годы жизни, наличие фото, мужчины/женщины и основная линия рода. Точный набор проверяется с фактической схемой данных проекта.

| Состояние | Требование |
| --- | --- |
| Закрыто | Видно, что фильтры активны, если действует хотя бы один. |
| Открыто без изменений | Показаны текущие значения; открытие не сбрасывает прошлое применение. |
| Изменения не применены | Можно применить или отменить их; экран показывает разницу только после применения. |
| Применено | Счётчик/индикатор активных фильтров обновлён; видим способ сбросить. |
| Пустой результат | Объяснить, что сочетание фильтров не нашло людей; дать сбросить фильтры. |

На mobile панель должна прокручиваться отдельно, а кнопки «Применить» и «Сбросить» оставаться понятными и доступными.

## 9. Статистика

Сводные показатели: количество людей, поколений, ветвей и фотографий; график распределения по поколениям. Значения строятся из данных, не подставляются декоративно.

- Загрузка — нейтральные скелетные блоки или краткий индикатор.
- Пустое состояние — объясняет, почему расчёт пока невозможен.
- Ошибка — отделена от нулевых значений.
- Большие числа, отсутствующие категории и длинные подписи не обрезают соседние карточки.
- При активных фильтрах явно сообщается, относится ли статистика ко всему древу или к видимой выборке.

## 10. Основные действия и уведомления

### «Поделиться»

Имеет состояния открытия диалога, копирования ссылки/успеха и ошибки. Показывает, что именно будет доступно по ссылке, если продукт предлагает публичность или ограничения доступа.

### «Печать» и «Создать видео»

Это отдельные будущие потоки из общей спецификации. До их реализации команда должна быть явно недоступна с коротким пояснением либо отсутствовать по решению Master. Не имитировать работающий экспорт.

### Системные уведомления

Подтверждение, успех, предупреждение и ошибка используют короткий заголовок, простое объяснение и следующий возможный шаг. Уведомление не перекрывает постоянные элементы управления и не зависит только от цвета.

## 11. Медиа, данные и безопасные заглушки

- Миниатюра открывает полноразмерное фото/медиа, если оно доступно.
- Ошибка загрузки фото не подменяется лицом, сгенерированным специально для реального родственника.
- Если фото нет, используется общий нейтральный силуэт. Его вид не кодирует возраст, пол, статус или ветвь.
- Неизвестные данные обозначаются последовательно; отсутствие значения не превращается в «0», случайный год или предположение.
- Реальные заметки и места могут быть длинными; в профиле допускается перенос/сворачивание, но не молчаливая подмена текста.

## 12. Обязательные кадры для prototype и визуальной регрессии

### Mobile

1. Древо без панелей и выбранного человека.
2. Выбран человек с фотографией.
3. Выбран человек без фотографии.
4. Открыт профиль без фото; проверен возврат к прежней позиции.
5. Поиск: ввод, результаты и отсутствие совпадений.
6. Меню «Ещё» и состояния будущих экспортных команд.
7. «Мой путь», «Моя ветвь», «Все поколения».
8. Фильтры: открытые, применённые и пустой результат.
9. Мини-карта и статистика.
10. Длинное имя, неизвестные годы и узкий экран.

### Desktop

1. Дерево в базовом состоянии и с выбранным человеком.
2. Правая панель профиля: информация, родственники, медиа, пустые данные.
3. Поиск, меню команд, фильтры, статистика и мини-карта.
4. Наведение и клавиатурный фокус.
5. Длинные имена, отсутствующие фото/годы, высокий уровень плотности поколений.

Прототип строится на 10–20 вымышленных людях с намеренно разными комбинациями данных. После screenshot review те же состояния повторно проверяются на реальном наборе примерно из 157 человек. Реальные сведения не копируются в фиктивные тестовые записи.

## 13. Открытые решения перед утверждением v1

- Точные ширины профиля, размеры карточек, высоты меню/панелей и точки переключения адаптивности.
- Точный формат частичных/неизвестных дат и длинных имён на карточках.
- Состав и источник критерия «основная линия» и назначения «Кто я?».
- Что именно считается «Моей ветвью» при нескольких супругах/родителях и неполных связях.
- Расчёт счётчиков в статистике при активных фильтрах.
- Состояния доступности и серверные требования для Share/Print/Video.
- Итоговые контрасты, тени, радиусы и текстовые размеры после screenshot review с tokens.

Пока эти пункты открыты, их нельзя самовольно разрешать в UI-коде. Прототип должен показать варианты, чтобы решение можно было принять на конкретном экране.
