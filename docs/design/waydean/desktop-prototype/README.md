# Waydean «Древо» — локальный desktop prototype

**Статус:** визуальный prototype для review; не production-интерфейс  
**Размер review-кадра:** 1440 × 900 CSS px  
**Данные:** тот же набор из 12 вымышленных людей, что и в mobile prototype; фото отсутствуют

## Открыть

Открой `index.html` в Edge или Chrome. Состояния доступны через `?state=`:

| Кадр | Параметр |
| --- | --- |
| D01 — древо и выбранный человек | `tree` |
| D02 — состояние keyboard focus | `focus` |
| D03 — поиск с результатами | `search` |
| D03 — поиск без результатов | `searchEmpty` |
| D04 — фильтры | `filters` |
| D04 — пустая выборка | `filtersEmpty` |
| D05 — профиль: родственники | `relatives` |
| D05 — профиль: медиа без фото | `media` |
| D06 — плотное дерево, все 12 записей | `dense` |
| Режим «Мой путь» | `path` |
| Режим «Моя ветвь» | `branch` |
| Меню «Ещё» | `menu` |

Примеры: `index.html?state=dense`, `index.html?state=search`.

## Ограничения

- Статические состояния и локальные переходы нужны для визуального review. Подключения к `drewo/`, Supabase и реальным данным нет.
- D06 показывает все 12 записей демо-набора и проверяет уплотнённую компоновку, но не заменяет будущую проверку на реальных ~157 людях.
- Поскольку демо-записи без фото, в карточках, профиле, родственниках и медиа используется один нейтральный силуэт головы и плеч без лица, глаз, носа и рта.
- Поиск, выбор человека, вкладки профиля, фильтры, сброс, режимы и управление деревом работают в пределах макета. Перетаскивание полотна мышью, масштабирование колесом/трекпадом и touch-жесты доступны в локальном превью; геометрическое поведение мини-карты, полноэкранный режим, серверные функции и экспорт пока не реализованы.
- «Поделиться», «Печать» и «Создать видео» не изображаются как готовые действия.
- Motion намеренно отсутствует до утверждения статических Desktop/Mobile кадров.
- Перетаскивание мышью и масштабирование колесом проверены в локальном браузере; pinch-жесты требуют отдельной проверки на сенсорном устройстве.

## Локальная проверка

До публикации в review-ветку проверены все параметры состояний, отсутствие JavaScript-ошибок, синхронизация выбранной карточки с профилем, поиск и выбор результата, вкладки родственников/медиа, фильтр с нулевой выдачей и возврат после сброса. Скриншоты созданы в Edge при 1440 × 900 CSS px.

Сопоставлять с [Desktop Master](../masters/desktop-master.md) и [каталогом экранных состояний](../states/screen-state-catalog.md). Mobile prototype доступен в [отдельной папке](../prototype/README.md); оба прототипа используют общую модель drag/zoom с кнопками как запасным способом.
