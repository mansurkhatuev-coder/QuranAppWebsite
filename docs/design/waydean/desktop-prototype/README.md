# Waydean «Древо» — локальный desktop prototype

**Статус:** визуальный prototype для review; не production-интерфейс  
**Размер review-кадра:** 1440 × 900 CSS px  
**Данные:** тот же набор из 12 вымышленных людей, что и в mobile prototype; фото отсутствуют

## Открыть

Открой `index.html` в Edge или Chrome. Состояния доступны через `?state=`:

| Кадр | Параметр |
| --- | --- |
| D01 — древо и выбранный человек | `tree` |
| D02 — состояние keyboard focus | `focus` |
| D03 — поиск с результатами | `search` |
| D03 — переход камеры к найденному человеку | `searchMotion` (выбрать результат) |
| D03 — поиск без результатов | `searchEmpty` |
| D04 — фильтры | `filters` |
| D04 — пустая выборка | `filtersEmpty` |
| D05 — профиль: родственники | `relatives` |
| D05 — профиль: медиа без фото | `media` |
| D06 — плотное дерево, все 12 записей | `dense` |
| Режим «Мой путь» | `path` |
| Режим «Моя ветвь» | `branch` |
| LOD — обзор всего дерева | `lod` (12 записей, масштаб 50%; +/− меняют уровень деталей) |
| Меню «Ещё» | `menu` |

Примеры: `index.html?state=dense`, `index.html?state=search`.
Desktop-сценарий камеры «Мой путь»: `index.html?state=path`.
На узких desktop-окнах шапка переносит навигацию на вторую строку; при ширине 761–980 px профиль занимает боковую колонку, ниже 760 px становится выдвижной карточкой, а до 460 px — нижней прокручиваемой панелью. Полотно резервирует место под управление, чтобы крайнее поколение и кнопки не накладывались друг на друга.

## Ограничения

- Статические состояния и локальные переходы нужны для визуального review. Подключения к `drewo/`, Supabase и реальным данным нет.
- D06 показывает все 12 записей демо-набора и проверяет уплотнённую компоновку, но не заменяет будущую проверку на реальных ~157 людях.
- Поскольку демо-записи без фото, в карточках, профиле, родственниках и медиа используется один нейтральный силуэт головы и плеч без лица, глаз, носа и рта.
- Поиск, выбор человека, вкладки профиля, фильтры, сброс, режимы и управление деревом работают в пределах макета. Перетаскивание полотна мышью, масштабирование колесом/трекпадом и touch-жесты доступны в локальном превью; геометрическое поведение мини-карты, полноэкранный режим, серверные функции и экспорт пока не реализованы.
- «Поделиться», «Печать» и «Создать видео» не изображаются как готовые действия.
- Desktop motion включает локальные кандидаты «Мой путь» и «Моя ветвь»: путь ведёт камеру от известного предка к выбранному человеку; ветвь проявляет потомков по поколениям и добавляет каждой появившейся группе один короткий импульс ±1,5 px. При этом масштаб сбрасывается, если прежний фокус обрезает новую структуру. Оба сценария прерываются новым вводом и учитывают reduced motion; режиссура остаётся на визуальном review по Motion Bible.
- Выбор результата поиска плавно центрирует человека и кратко выделяет карточку. Текущие фильтры сохраняются; если фильтр скрывает выбранного человека, прототип объясняет это и не перестраивает выборку. Desktop LOD переключает детали по фактической экранной ширине карточки с гистерезисом; пороги пока кандидатные.
- Атмосферный фон слегка следует за камерой только во время движения и возвращается в покой после него; постоянного фонового движения нет. Для отключения длинных переходов и параллакса учитывается `prefers-reduced-motion`.
- В preview есть профили motion High / Medium / Low. Автовыбор — кандидатная эвристика по экономии трафика, числу ядер и памяти; для сравнения вручную открой `?state=branch&quality=low`, `?state=branch&quality=medium` или `?state=branch&quality=high`. OS-настройка уменьшения движения всегда важнее профиля. Реальные пороги и переход вниз при пропущенных кадрах ещё требуют device trace.
- Перетаскивание мышью и масштабирование колесом проверены в локальном браузере; pinch-жесты требуют отдельной проверки на сенсорном устройстве.

## Локальная проверка

До публикации в review-ветку проверены все параметры состояний, отсутствие JavaScript-ошибок, синхронизация выбранной карточки с профилем, поиск и выбор результата, вкладки родственников/медиа, фильтр с нулевой выдачей и возврат после сброса. Скриншоты созданы в Edge при 1440 × 900 CSS px.

Сопоставлять с [Desktop Master](../masters/desktop-master.md), [Motion Bible](../motion/motion-bible.md) и [каталогом экранных состояний](../states/screen-state-catalog.md). Основной screenshot review остаётся 1440 × 900 CSS px; дополнительно проверены узкие ширины 900, 620 и 390 px на перенос шапки, панель профиля и пересечения дерева с управлением. Mobile prototype доступен в [отдельной папке](../prototype/README.md); оба прототипа используют drag/zoom с кнопками как запасным способом.
