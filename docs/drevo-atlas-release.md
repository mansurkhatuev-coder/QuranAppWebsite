## Общий интерфейс

Редактируйте навигацию в drewo/waydean-preview.html. Команда `node scripts/atlas/sync-editor.mjs --write` переносит её в страницы из реестра. Без аргументов команда проверяет совпадение. Сервер создаёт новые страницы из drewo-reklama. SVG хранятся в assets/drewo-icons.svg.

## Публичные показатели

Ответственный за выпуск готовит вне репозитория JSON-массив разрешённых снимков. У записи есть treeDir, file (путь к JSON родословной), active и aggregateConsent. Для явно согласованной географии можно указать groupId, teipId и settlementId из каталога. Перед каждым выпуском учитываются отзыв согласия и прекращение доступа. Неизвестные связи оставляют пустыми.

`node scripts/atlas/public-summary.mjs /путь/к/реестру.json` выдаёт агрегаты в stdout. В atlas/data/public-summary.json включают только проверенный результат. Входной реестр и семейные снимки туда не помещают. Показатели отражают дату выпуска. Для достоверной глубины источник должен содержать полное дерево. Одна запись о человеке в двух разных деревьях учитывается дважды.

Минимальный размер группы — пять разных родословных. Разбиение скрывается целиком, если одна из его ячеек меньше порога. Число записей о людях скрывается при преобладании одной семьи. Интервалы снижают точность сопоставления. До выпуска сопоставьте разрешённые разрезы и предыдущие снимки на риск косвенного раскрытия. Для отзыва замените опубликованную сводку пересчитанной. История ранее опубликованных агрегатов сохраняется в Git.

Команды для повторной проверки из корня репозитория

```sh
node --test drewo/*.test.mjs scripts/atlas/*.test.mjs docs/design/waydean/export/workshop-model.test.mjs docs/design/waydean/export/print-prototype/*.test.mjs
node scripts/atlas/sync-editor.mjs
deno check supabase/functions/publish-drewo/index.ts
deno test --allow-read supabase/functions/publish-drewo/*test.ts
python scripts/atlas/test-entry.py --browser chromium
python scripts/atlas/test-entry.py --browser webkit
```

Для браузерных команд нужны Python с Playwright и установленные движки Chromium и WebKit. Ключ `--executable` позволяет указать путь к браузеру.

## Что остаётся перед публикацией

- На изолированном сервере с отдельным репозиторием пройти создание, первый вход, сохранение первой правки и повторное открытие. Проверить резервное копирование и восстановление на тестовой семье. Проверить тарифные ограничения без операций с оплатой действующих семей.
- На физических iPhone и Android проверить системную клавиатуру, безопасные отступы, масштабирование, жесты, приглашения из Instagram и Telegram, а также обновление ранее установленной PWA. На слабом устройстве замерить время загрузки карты и плавность перемещения.
- Перед первой публикацией семейных показателей сверить согласия. Для хранения конфиденциальных имён и географии между устройствами требуется отдельная миграция с контролем доступа к чтению.
- Удалённые из сценария развёртывания запасные пароли остаются в истории Git. Проверить в доверенной среде, используются ли они ещё, и согласовать замену с владельцами соответствующих семей.
