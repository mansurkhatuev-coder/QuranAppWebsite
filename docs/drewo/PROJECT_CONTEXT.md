# Древо — контекст проекта

Назначение: генеалогическая платформа. Интерактивный 3D-атлас — главная страница, а не самостоятельный исторический портал. Основной продукт — создание и использование семейных родословных.

## Архитектура
- `atlas/` — карта, каталог, публичный вход, мастер/переход к созданию, семейная география.
- `nek/` и `t/` — совместимость старых входов и приглашений; в PR #262 вход переносится в атлас.
- `trees/` — кабинет оператора. Личная авторизация Supabase Auth не равна разрешению управлять всеми семьями.
- `drewo/waydean-preview.js` и общий CSS — редактор; `drewo/waydean-preview.html` — общий шаблон навигации.
- `trees/registry.json` — реестр. Не считать список неизменным: проверять при каждом релизе. `drewo-reklama/` — демонстрационный шаблон новых древ.
- `supabase/functions/publish-drewo/` — серверная авторизация, создание, редактирование, резервные копии и биллинг.
- `scripts/atlas/sync-editor.mjs` — проверка/синхронизация навигации зарегистрированных древ. Не путать с полной синхронизацией всех ресурсов.
- `scripts/atlas/public-summary.mjs` — подготовка только согласованных публичных агрегатов.

Ограничения: не менять действующие семейные данные, доступы, оплату и резервные копии без обоснованной миграции. Не публиковать сырые личные данные или секреты. Не считать закрытие UI защитой хранилища. Не включать тестовые записи в продакшен. Изменения должны распространяться на все действующие и будущие древа и сохранять старые приглашения.
