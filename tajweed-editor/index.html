Как работать

      
    
        
  • Цвет — основное правило на фрагменте.
    • 
        
  • Несколько правил — можно на одном месте; второе видно точкой снизу.
    • 
        
  • Ударение — черта сверху, отдельный слой.
    • 
        
  • Скрытый — для элементов вроде сада в «Аллах», которых нет отдельно в транслите.
    • 
        
  • Мадды — отдельно: 2, 2–4–6, 4–5, 6.
    • 
        
  • Межзубные — правило 9 для ث ذ ظ: пунктир снизу остаётся даже если сверху цвет тафхима/мадда (удобно для ظ).
    • 
        
  • Библиотека — несколько азкаров в одном браузере; переключай сверху.
    • 
        
  • Добавить — пустой документ, копия текущего или шаблон (Фатиха, Каусар и др.). Свои черновики не затираются.
    • 
        
  • Транслитерация — поле под арабским: вставь чеченский текст, затем размечай на «бумаге».
    • 
        
  • Экспорт всего — скачивает все документы одним JSON, когда будешь готов.
    • 
        
  • Облако — «Облако ↑/↓» пишет черновик в Supabase; «Опубликовать» кладёт JSON на waydean.ru для приложения.
    • 
        
  • Прод — подтянуть уже опубликованный пак с сайта.
    • 
        
  • Автосейв — локальный черновик в этом браузере; облако — общий для админов.
    • 
        
  • Бэкап — перед записью хранится предыдущий снимок; если меток стало меньше, при открытии подтянется более полный бэкап.
    • 
        
  • Экспорт всего — лучшая страховка: скачай JSON себе на устройство.
    • 
        
  • Горячие клавиши: 1–9, A, H, Del, Ctrl+Z.
