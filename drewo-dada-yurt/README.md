# Дада-юрт — родовое древо

Публичная страница: https://waydean.ru/drewo-dada-yurt/

- Данные: `family-tree.json` (встроены также в `index.html` → `#tree-data`)
- Пароль правок/сохранения — `баташ` (у «Хьоти некъ» по-прежнему `гуно`)
- «Сохранить» пишет в этот каталог через Edge Function `publish-drewo` с `treeDir: "drewo-dada-yurt"`
- Бэкапы: `drewo-dada-yurt/backups/`
- Вид по умолчанию: все линии; кнопка «Линия Дида» фильтрует ветку Дида

## Замечания по данным со скана

- Вис-Мохьмад: на скане смерть `204` → в данных `2004`
- Дауд (1964) — брат Виса под Г1азали
- Палочка в именах — цифра `1` (`М1ама`, `Г1азали`, `Ц1агара`)
