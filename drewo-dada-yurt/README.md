# Дади-Юрт — родовое древо

Страница: https://waydean.ru/drewo-dada-yurt/

## Вход

**Своё имя из списка** + **обычный пароль** (`баташ`, либо сменённый в «Управление»).  
Тёзок отличаем по отцу и годам. Сессия ~30 дней; в меню — **Выйти**.

## Фото

Карточка (долгое нажатие) → добавить фото. Кружок на древе; файлы в Supabase Storage, бэкапы без картинок. После фото — **Сохранить**.

## Правки

- Обычный пароль: связи, сохранение, фото.
- Суперпароль `DREWO_DADA_YURT_SUPER_PASSWORD`: бэкапы, блок правок, смена пароля.
- «Сохранить» через `publish-drewo` с `treeDir: "drewo-dada-yurt"`.
- Вид по умолчанию: все линии; «Линия Дида» — фильтр.

## Заметки по данным со скана

- Вис-Мохьмад: на скане смерть `204` → в данных `2004`
- Дауд (1964) — брат Виса под Г1азали
- Палочка в именах — цифра `1` (`М1ама`, `Г1азали`, `Ц1агара`)
