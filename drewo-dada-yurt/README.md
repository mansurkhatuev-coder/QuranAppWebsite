# Родовое древо Дада-юрт

Данные распознаны с TIFF-скана («РОДОВОЕ ДЕРЕВО»).

- Публичный URL (когда встроим страницу): `https://waydean.ru/drewo-dada-yurt/`
- Формат как у `drewo/family-tree.json`: `id`, `name`, `sons`, опционально `born` / `died` / `note`
- Палочка в именах — цифра `1` (как в «Хьоти некъ»: `Г1азали`, `М1ама`, `Ц1агара`)

## Важно про связи

В нижней части скана **вертикальные стопки под одним человеком — это братья (сыновья)**, а не цепочка отец→сын→внук.

## Замечания по распознаванию

| Место | Как в JSON | Комментарий |
|-------|------------|-------------|
| Вис-Мохьмад | `died: 2004` | На скане обрез/опечатка `204` |
| Дауд под Г1азали | брат Виса, `born: 1964` | Не сын Виса (года не сходятся) |
| 1елам-Паша | с `1` | На скане выглядит как `ІЕЛАМ-ПАША` |
| Ризауди | `Ризауди` | OCR также давал `РИЗАВДИ` |

Имеет смысл пробежать глазами ветки **Сайд-Мохьмад (1елам-Паша)**, **Вахита (Мати)** и правый край (**Сиражди / Рамзан / Ваха**).
