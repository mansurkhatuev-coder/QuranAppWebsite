# Хьоти некъ — семейное древо

Публичная страница: https://waydean.ru/drewo/

- Правки связей — кнопка «Редактировать», обычный пароль `гуно` (регистр не важен). Имя/годы/био — из карточки (долгое нажатие).
- «Сохранить» пишет `drewo/index.html` в этот репозиторий через Edge Function `publish-drewo` и кладёт бэкап в `drewo/backups/` (до 30 копий).
- Восстановление бэкапа, смена обычного пароля и блок правок — суперпароль этого дерева (`DREWO_SUPER_PASSWORD`). У Дади-Юрт свой: `DREWO_DADA_YURT_SUPER_PASSWORD`. После задания секретов задеплойте функцию `publish-drewo`.
