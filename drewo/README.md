# Хьоти некъ — семейное древо

Страница: https://waydean.ru/drewo/

## Вход

Перед просмотром: **своё имя из списка** + **обычный пароль** семьи (`гуно`, либо тот, что задан в «Управление»).  
Тёзок пока отличаем по отцу и годам. Сессия на телефоне помнится ~30 дней; в меню есть **Выйти**.

Неверный пароль: после **5 попыток** сервер блокирует ввод примерно на **15 минут** (с одного IP).

## Фото

В карточке человека (долгое нажатие) — добавить/сменить/убрать фото.  
На древе появляется кружок. Файлы лежат в Supabase Storage (`drewo-photos`), в JSON только метка `photo`. Бэкапы без картинок. После фото нажмите **Сохранить**.

## Правки

- Связи — «Редактировать», обычный пароль.
- Имя / годы / био / фото — из карточки.
- «Сохранить» пишет дерево через `publish-drewo` и кладёт бэкап в `drewo/backups/`.
- Управление и восстановление бэкапа — суперпароль (`DREWO_SUPER_PASSWORD`).
