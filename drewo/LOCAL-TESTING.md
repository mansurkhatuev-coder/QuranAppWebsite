# Локальная тестовая сборка Waydean

## Запуск

Для запуска двойным щелчком открой `Start-Waydean-Local.cmd` в корне репозитория. В PowerShell из корня репозитория эквивалентная команда:

```powershell
.\scripts\start-waydean-local.ps1
```

Скрипт поднимет статический сервер только на этом компьютере (`127.0.0.1`), откроет главное древо и выберет порт 8784–8800. Если сервер уже запущен для этой сборки, откроет его повторно. Сборка определяется уникальным маркером, поэтому уже открытый сервер из другого рабочего каталога не будет ошибочно принят за кандидата. Python 3 должен быть установлен.

Прямой адрес главного экрана:

```text
http://127.0.0.1:8784/drewo/waydean-preview.html?state=all-tree
```

Если скрипт выбрал другой порт, он напечатает точный адрес.

## Что можно проверять

- Полное дерево HOTI из локального снимка `drewo/family-tree.json`.
- Карточку, родственников, медиа и локальное добавление ребёнка: выбери человека → «Информация» → «Добавить ребёнка», укажи имя и данные, затем проверь предварительный вариант и нажми «Добавить в дерево». Чтобы сохранить правки, открой «Информация» и выбери «Сохранить локально». Это меняет только копию в этом браузере.
- «Мой путь», «Моя ветвь», все поколения, поиск и фильтры. Чтобы включить свой путь, выбери карточку → «Отметить как меня»; отметку можно сбросить или перенести на другого человека, она хранится отдельно для HOTI/demo в этом браузере.
- Масштабирование, мини-карту, статистику и мобильную раскладку.
- Экспорт дерева: кнопка «Экспорт» открывает Print Studio, где доступны SVG и печать/PDF.
- Видео: «Ещё» → «Создать видео» открывает «Историю рода», передавая выбранного человека и режим дерева. В студии можно выбрать область, человека, даты и формат кадра, просмотреть сцены и скачать MP4. Файл сохраняется в `H:\CodexBuildTemp\WaydeanRemotion\waydean-local-renders`.
- Установку Waydean как отдельного приложения через «Ещё» → «Приложение и уведомления»; если prompt браузера не появляется, панель показывает ручные шаги.
- После первой загрузки — повторный локальный запуск оболочки и снимка HOTI без сети. Изображения кешируются по мере открытия.
- Разрешение уведомлений и тестовое уведомление на этом устройстве. Оно не подписывает локальный preview на production push.
- Вымышленный набор с ограниченным редактированием — по адресу `?fixture=master`; сохранение там действует только в текущей вкладке.

### Управление видом древа

- Кнопка с тремя линиями слева от логотипа скрывает панель действий; нажми ещё раз, чтобы вернуть её. Крестик на профиле полностью освобождает его колонку, кнопка «Профиль» справа открывает профиль снова.
- Крути колесо мыши или трекпада над полотном, чтобы менять масштаб вокруг курсора; перетаскивай древо, чтобы перемещаться.
- На телефоне используй pinch для масштабирования и перетаскивание для перемещения.
- Кнопки `−` и `+` либо клавиши `−` и `+` меняют масштаб; `0` показывает текущую схему целиком.
- Перетаскивай рамку мини-карты или нажми в нужное место; стрелки при фокусе двигают обзор.
- Обычный щелчок по видимой карточке выбирает человека и открывает его профиль, сохраняя текущий набор карточек. Поиск и переход к родственнику намеренно перестраивают вид вокруг нового человека.
- «Древо» и «Все поколения» возвращают всё дерево и сбрасывают фильтры. «Мой путь» показывает предков отмеченного человека; его кнопка внизу возвращает полное древо. «Моя ветвь» показывает выбранный фрагмент; обычный щелчок по карточке не меняет состав видимых людей.
- Логотип открывает всё дерево; в «Ещё» → «Текущее древо» можно вернуться к прежнему экрану. Если Waydean не загрузилась, доступны повторная загрузка и переход к прежнему экрану.

Параметр `?fixture=master` открывает отдельные вымышленные записи. Ограниченное редактирование и сохранение в памяти доступны только там; перезагрузка сбрасывает демонстрационные правки.

Чтобы вернуться к общему виду HOTI-древа, выбери «Древо» или «Все поколения».

`Start-Waydean-Local.cmd` также запускает Remotion Studio на `127.0.0.1:8781`. Для первого запуска нужны Node.js LTS, npm и установленный Chrome или Edge; зависимости Remotion установятся автоматически и повторно не скачиваются. Сервер доступен только на этом компьютере. Если диск H недоступен, временные файлы переходят в `%LOCALAPPDATA%\Waydean\Remotion`.

## Граница с production

Главный локальный экран читает статический снимок из checkout и не меняет дерево на `https://waydean.ru/drewo/`. Для account-маршрута предусмотрена кнопка `Waydean · тест` только после входа с ролью `super`; страница повторно подтверждает подписанную сессию действием `auth`. Само дерево остаётся read-only. В account-маршруте пользователь может отдельно включить/отключить push, подтвердив пароль редактора; это меняет только подписку устройства в серверном push-файле. Локальный preview не вызывает эту операцию. Серверное сохранение дерева, фото, резервные копии и история остаются открытыми. «Стиль: Премиум» на старой странице показывает оформление, а не платную подписку.

Текущая рабочая страница в репозитории остаётся `drewo/index.html` и не заменяется этим preview. Ссылка «Текущее древо» ведёт туда только внутри локального кандидата. Ничего не публикуется при локальном запуске.
